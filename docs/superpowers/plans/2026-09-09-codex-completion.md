# Codex 调用完成机制修复

用户已批准：修复完成识别，随后另给视频验收。本轮首个投入检查点为 30 分钟，非工期承诺。

## 目的与边界

Codex 使用 `exec --json`，收到最终 agent_message 与 turn.completed 后确认成功；进程退出用于资源收尾。保持既有翻译接口、提示词与业务 JSON 校验。Claude/Gemini 继续沿用原实现。撤回统一 90 秒实验，保留 60 秒等待完成的上限。

不加入重试、会话恢复、界面重做或视频渲染修改。

## 实施与退出条件

1. 真实本地子进程复现完成后挂起，先观察测试失败。
2. 实现分块 JSONL 读取、完成与失败识别；正常退出宽限 250ms，SIGTERM 后 250ms 仍存活则 SIGKILL，close 后交付结果。
3. 检查缺少完成事件、明确失败、损坏输出、超限和真实超时；保留旧 CLI 的退出校验。
4. 做一次无需素材的真实 Codex 连接，记录事件类型和耗时，不记录认证、提示词或推理正文。
5. 更新研发日志，区分代码验证、真实连接和待完成的新视频验收。

完成能返回、失败能识别、调用进程能结束即停止扩展。真实服务未返回完成事件应据实报失败，不通过延长等待或接受部分答案伪造成功。提交和推送另由用户指示。
