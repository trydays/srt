# 自动字幕第一版设计

日期：2026-09-06

状态：已完成并经用户口头确认，等待书面审阅

## 1. 阶段冻结

### 唯一目的

打通第一条真实的自然语言视频编辑链路：用户输入“给视频加字幕”，SRT 在本机识别整段视频中的人声，并生成可预览、可修改文字、可整批撤销的字幕。

### 可直接查看或运行的成果

1. 环境检测页能够识别并准备 `faster-whisper` 与固定的 Small 模型。
2. 编辑器收到“给视频加字幕”后，生成一条包含多个时间段字幕块的字幕轨。
3. 播放视频时，当前字幕同步显示在画面下方。
4. 用户选择字幕块后可以修改文字。
5. 用户可以撤销本次整批字幕生成。

### 明确不做

- 不做淡入、淡出或其他视频效果。
- 不做组件拖入剪辑，也不改造组件库；组件库正式降为预览入口的清理另行安排。
- 不做通用自然语言编辑协议，只接受本阶段唯一的字幕指令。
- 不做完整多轨时间轴、字幕块拖动、字幕块边缘调整或逐字时间戳。
- 不做字幕样式选择、模板、翻译、说话人识别或多模型选择器。
- 不做通用撤销栈，只保存本次字幕操作所需的一层快照。
- 不做 FFmpeg 硬字幕烧录、软字幕封装或最终视频导出。
- 不做云端语音识别、供应商切换或复杂断点恢复。
- 不重构与字幕纵向链路无关的旧代码。

### 时间与投入上限

- 实施时间上限：8 小时。
- 支撑性工作上限：2 小时；仅限取得媒体路径、固定模型准备和字幕进程桥接。
- 到 4 小时时必须已经能通过固定转录结果，在真实编辑器中看到字幕轨与画面字幕。
- 若任一支撑模块超过原估算两倍，立即停止并报告，不继续补建平台能力。

### 立即结束条件

满足以下条件即停止本阶段，不继续“顺手完善”：

1. 在检测页准备 Small 模型后，真实短视频能够完成本地转录。
2. “给视频加字幕”能够生成带起止时间的字幕块。
3. 播放时字幕与对应时间段同步显示。
4. 选中字幕块可以修改文字，刷新后仍属于当前项目。
5. 一次撤销能够移除本次字幕；重新生成时能够恢复被替换的上一版字幕。
6. 转换或转录失败时不留下半成品，并显示对应的可读原因。

## 2. 已选方案

采用现有应用管理的 Python 3.12 环境与 `faster-whisper`，固定使用多语言 Small 模型。官方模型仓库当前体积约 486 MB：

https://huggingface.co/Systran/faster-whisper-small/tree/main

不采用以下路线：

- `whisper.cpp`：项目没有匹配的可执行程序，且现有模型下载脚本与 `faster-whisper` 格式不相连，会扩大安装与打包范围。
- 云端转录：会引入音频上传、网络依赖和持续费用。

## 3. 职责边界

### 本地 CLI Agent

Agent 只负责把自然语言转换成一个严格的结构化指令：

```json
{"type":"generate_subtitles"}
```

“给视频加字幕”固定表示识别整段视频。Agent 不生成命令、不运行 Python 或 FFmpeg，也不读取或修改项目文件。

本阶段不建立通用指令模式，不接受额外字段，也不扩展时间范围语法。

### SRT 主进程

SRT 负责：

1. 取得用户已导入视频的稳定本地路径。
2. 验证字幕运行环境与固定 Small 模型是否已经在检测页准备好。
3. 通过固定程序和固定参数启动本地转录，不执行 Agent 返回的命令文本。
4. 校验转录结果并返回字幕片段。
5. 将技术错误归类为少量稳定、可读的失败原因。

### 编辑器

编辑器负责：

1. 展示合并式处理记录。
2. 在全部片段成功返回后，原子地写入一条字幕轨。
3. 根据播放时间显示当前字幕。
4. 修改选中字幕块的文字。
5. 按项目保存字幕，并提供本次生成的一层撤销。

## 4. 数据流

1. 用户导入视频。桌面版保留浏览器预览所需的文件对象，同时取得该文件的本地路径并记录到当前项目。
2. 用户输入“给视频加字幕”。
3. 对话记录显示“转换编辑指令：转换中”。
4. 本地 CLI 返回唯一合法指令 `generate_subtitles`。
5. 对话记录第一行变为成功，第二行显示“生成字幕：生成中”。
6. SRT 检查视频路径、Python、`faster-whisper` 和固定 Small 模型。
7. 本地转录程序直接读取视频，输出字幕片段数组。第一版使用模型自带的语言自动识别，不增加语言设置界面。
8. SRT 只接受以下片段数据：

```json
[
  {"start": 0.42, "end": 2.18, "text": "大家好"}
]
```

9. 每个片段必须有有限数值的开始与结束时间、`start >= 0`、`end > start` 和非空文字。无效结果整体失败，不部分写入。
10. 编辑器保存现有字幕快照，然后一次性替换当前字幕轨。重复执行不会叠加两条重复字幕轨。
11. 对话记录第二行变为成功，并显示生成的字幕数量。

## 5. 环境检测与模型准备

### 检测页呈现

沿用现有暖白、陶土橙配色和现有工具列表，不创建新的模型中心。

现有 Whisper 项目改为一个合并的“Whisper 字幕”准备项，描述为：

- `faster-whisper + Small 本地模型`
- `约 486 MB，下载后可离线使用`

“语音字幕可用”必须同时满足：

1. 应用管理的 Python 3.12 可用。
2. `faster-whisper` 可导入。
3. 应用固定模型目录中存在 `model.bin`、`config.json`、`tokenizer.json` 和 `vocabulary.txt`，且文件大小均大于零。

当前仅执行 `pip show faster-whisper` 就报告就绪的行为必须修正，避免无模型时的假阳性。

### 准备过程

1. 用户在检测页点击“准备字幕能力”。
2. 现有确认弹窗明确展示下载体积、位置和步骤。
3. 确认后弹窗关闭，检测页对应行显示“准备中”，页面保持可操作，不把用户困在弹窗中。
4. 应用只下载固定的 `Systran/faster-whisper-small` 到应用管理目录。
5. 完成后重新检测，该行和“语音字幕”能力均显示可用。
6. 失败时该行显示“准备失败，可重试”；不在编辑器内重新触发隐式下载。

本阶段不提供下载暂停、多个镜像源、模型切换、模型删除或版本管理。

## 6. 编辑器界面与交互

### 对话记录

沿用已确认的压缩结构：一条用户消息对应一张状态卡，不增加独立通知。

状态卡只有两行：

1. 转换编辑指令：转换中 / 成功 / 失败。
2. 生成字幕：等待 / 生成中 / 成功 / 失败 / 未执行。

成功后标题显示“字幕已生成”，并显示片段数量。卡片内提供“撤销本次字幕”。

### 字幕轨

- 在现有时间轴区域只增加一条“字幕”轨，不借此建设完整多轨系统。
- 每个字幕片段显示为一个按起止时间定位和定宽的块。
- 点击字幕块会定位播放头，并把其文字放入紧邻时间轴的单行编辑框。
- 保存后立即更新字幕块、画面字幕和项目存储。
- 字幕块不可拖动，也没有左右调整手柄。

### 画面字幕

- 字幕显示在视频画面下方安全区域。
- 使用中性的白字与半透明深色底，确保预览可读。
- 编辑器外壳、按钮、状态和轨道全部复用现有设计令牌，不改变产品主色。
- 本阶段不提供字号、字体、位置、颜色或动画设置。

## 7. 项目状态与撤销

每个项目保存一份字幕状态：

```json
{
  "segments": [
    {"id":"segment-1","start":0.42,"end":2.18,"text":"大家好"}
  ]
}
```

字幕数据按当前项目 ID 隔离。重新进入项目时恢复字幕轨和播放预览。

生成或重新生成字幕前，仅保存上一份字幕数组作为本次操作快照：

- 首次生成后撤销：恢复为空字幕轨。
- 重新生成后撤销：恢复生成前的字幕轨。
- 本阶段不记录多步历史，也不对单次文字修改提供撤销栈。

## 8. 错误处理

所有失败都保持同一张状态卡，不产生额外消息。至少区分：

- 未选择或找不到本地 CLI：提示返回检测页选择本地 CLI。
- Agent 超时：提示“编辑指令转换超时，请重试”。
- Agent 输出不合法：提示“未能识别为字幕指令”。
- 当前视频路径不可用：提示重新导入视频。
- Python、`faster-whisper` 或 Small 模型缺失：提示到环境检测页准备“Whisper 字幕”，并提供返回检测页的入口。
- 没有识别到有效人声：提示“未检测到可生成字幕的清晰人声”。
- 本地转录程序失败：提示“字幕生成失败，请重试”，并保留可供开发诊断的错误类别。

失败时：

1. 不覆盖现有字幕。
2. 不写入空字幕轨。
3. 不把所有错误误报成“请选择本地 CLI”。

## 9. 测试与验收

### 单元测试

- 本地 CLI 仅接受 `{"type":"generate_subtitles"}`，拒绝解释文字、额外字段和旧的淡入输出。
- 环境检测在只有 Python 包、没有 Small 模型时报告“未准备”。
- 模型准备只使用固定模型 ID 与固定应用目录。
- 转录服务只使用固定程序和参数，并校验每个字幕片段。
- 不合法、空白或失败的转录结果不产生部分字幕。
- 字幕按项目保存，重新生成只保留一层可恢复快照。

### 编辑器流程测试

使用固定的模拟转录片段验证：

1. 输入“给视频加字幕”。
2. 同一张卡依次显示指令转换和字幕生成状态。
3. 成功后只出现一条字幕轨和正确数量的字幕块。
4. 播放头进入片段时间后显示对应字幕，离开后隐藏。
5. 修改文字后，轨道、画面和项目存储同步更新。
6. 撤销首次生成后移除字幕；撤销重新生成后恢复上一版。
7. 任一失败不改变原字幕。

### 本机真实验收

不在持续集成中下载模型。实施完成后在当前 Mac 上通过检测页准备一次 Small 模型，并用一段短中文口播视频验证真实转录、同步预览、文字修改和整批撤销。

## 10. 用户可见完成度与内部完成度

### 用户可见完成度

- 可以在检测页一次准备字幕能力。
- 可以用一句自然语言生成真实字幕。
- 可以在视频和时间轴中看到结果、修改文字并撤销。

### 内部完成度

- 字幕指令有严格的唯一协议。
- 视频路径能够安全交给固定本地转录程序。
- 模型就绪状态不再假阳性。
- 转录结果经过校验并按项目原子保存。

内部完成度只服务于上述用户可见结果，不以平台化、复用性或极端故障恢复为本阶段目标。
