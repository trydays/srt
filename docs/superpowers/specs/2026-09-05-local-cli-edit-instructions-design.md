# SRTP 本地 CLI 结构化编辑指令设计

## 目标

让用户已明确选定的本地 Codex CLI、Claude Code 或 Gemini CLI 将自然语言编辑请求转换为 SRTP 可校验的结构化编辑指令。SRTP 负责验证并应用合法指令；Remotion 以后从编辑状态渲染。本阶段不允许 CLI 直接执行 shell、FFmpeg、Remotion 或写项目文件。

## 用户流程

1. 用户在环境页选择一个本地 CLI；未选择或已失效时，编辑器不自动替代。
2. 用户在编辑器输入自然语言请求。
3. renderer 调用专用 `local-cli:translate-edit` 接口。
4. 主进程仅调用当前有效的已选 CLI，并要求其只输出固定 JSON。
5. 主进程验证 JSON；合法操作返回 renderer 并原子应用到编辑状态，非法、超时或失败结果不应用任何操作。
6. 编辑器显示“已生成编辑指令”或可理解的失败原因。

## 数据契约

接口只返回已验证的指令，不返回 CLI 路径、版本、原始输出、环境变量或任意命令。

```js
{
  operations: [
    { type: 'add_effect', effect: 'fade_in', start: 0, duration: 1.2 },
    { type: 'set_speed', value: 1.5 }
  ]
}
```

第一版白名单操作：`add_effect`、`set_effect_timing`、`set_speed`、`trim`、`set_mute`。效果名称、字段和数值范围由 SRTP 固定校验；未知操作、额外危险字段、非 JSON 或部分无效结果全部拒绝。

## 模块边界

- **renderer**：提交自然语言、显示请求/成功/失败状态，并将已经验证的操作写入现有编辑状态与时间轴。
- **preload**：只公开翻译调用；不公开 CLI 路径、通用命令或文件访问。
- **main process**：读取已选 CLI、以固定提示调用它、限制超时/输出，并验证 JSON schema。
- **selected CLI**：只产生 JSON 编辑意图，不取得任意命令执行、渲染、安装、认证或文件写入能力。

## 旧界面处理

环境检测页中的“AI 效果翻译”云端/Ollama 配置 UI、自动检测与手动配置逻辑将在本阶段新入口可用时移除。旧的云端/Ollama 底层接口是否一并删除，取决于实现时是否仍有其他调用方；不假定它们可被新 CLI 阶段直接替代。

## 失败语义

- 未选择、选择失效、CLI 启动失败、超时、非零退出、非 JSON 与 schema 校验失败均不改变编辑状态。
- 不自动切换 CLI，不回退到云端/Ollama，不执行原始文本或命令。
- 错误信息面向用户，不泄露路径、原始 CLI 输出、环境变量或令牌。

## 测试与验收

- 单元测试：选择失效、固定调用边界、成功 JSON、无效 JSON、未知/越界操作和无副作用拒绝。
- Electron E2E：一次成功的自然语言到时间轴操作流程；一次失败结果不改变编辑状态的流程。
- 手工 Mac 验证：选择已安装 CLI，提交一个受支持请求，确认合法指令可见且时间轴更新。

本阶段完成条件：已选 CLI 能生成并通过验证的白名单编辑指令；失败不改变状态；旧环境页 AI 翻译 UI 已移除；没有新增任意命令执行、直接渲染或自动 CLI 切换。

## 明确延期

Remotion 执行/导出、CLI 安装登录模型控制、多轮 agent 对话、更多 CLI、自定义注册表、多 CLI 回退、直接 FFmpeg/shell 命令、CLI 写文件，以及复杂编辑操作均留待后续独立阶段。
