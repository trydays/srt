# SRTP 本地 CLI 效果指令设计（冻结范围）

## 开工冻结

1. **唯一目的**：让用户已选的本地 CLI 将一句自然语言效果请求转换为一个受限的 `add_effect` 指令。
2. **可见成果**：用户在编辑器输入“添加淡入”后，看到“已生成编辑指令”反馈和一个新增的时间轴效果标记。
3. **明确不做**：不支持其他编辑操作、通用 schema 框架、供应商抽象、多轮 agent、回退系统、直接 shell/FFmpeg/Remotion 执行、CLI 写文件、安装/登录/模型控制或更多 CLI。
4. **时间上限**：实施后 60–90 分钟内必须出现编辑器可见检查点；总硬上限 3 小时；支撑性工作不超过约四分之一。若支撑工作超过估计两倍，停止并报告。
5. **立即结束**：一次成功流程、一次非法输出拒绝流程和手工 Mac 验证通过后立即停止。

这些阈值是本阶段的实用治理规则，不是通用行业标准。

## 最小流程

1. 用户已在环境页明确选择一个本地 CLI；未选择或选择失效时，编辑器提示用户选择，不自动替代。
2. 用户输入自然语言效果请求。
3. renderer 调用专用 `local-cli:translate-effect`。
4. 主进程只调用当前有效的已选 CLI，以固定提示要求输出一个 JSON 指令。
5. 主进程验证 JSON；仅合法指令返回 renderer。
6. renderer 将指令添加为现有时间轴效果标记，并显示“已生成编辑指令”。

## 最小数据契约

```js
{
  type: 'add_effect',
  effect: 'fade_in'
}
```

`type` 必须恰为 `add_effect`，`effect` 必须属于 SRTP 当前已有的效果白名单。非 JSON、未知字段、未知效果、缺失字段、数组、批量操作或任何额外操作均被拒绝；失败时不改变时间轴。

## 最低充分边界

- **renderer**：提交请求、显示请求/成功/失败状态，并将已验证的单个效果写入现有时间轴状态。
- **preload**：只公开翻译效果调用；不公开 CLI 路径、通用命令或文件访问。
- **main process**：读取已选 CLI、固定提示、短超时、JSON 解析和上述最小字段校验。
- **selected CLI**：仅产生一个 JSON 效果意图，不获得任意命令执行、渲染、安装、认证或文件写入能力。

不在本期预防平台级并发、复杂恢复或跨供应商异常。任何新增工作必须满足：不做就无法通过本规格验收、会造成现实安全/法律/数据损失风险，或经用户明确批准；否则延期。

## 旧界面处理

环境检测页中的“AI 效果翻译”云端/Ollama UI、自动检测和手动配置逻辑，在上述本地 CLI 流程已经可见且可验证后移除。旧底层接口不在本期顺带重构或删除。

## 测试与验收

- 聚焦单元测试：已选 CLI 的固定调用、一个合法 `add_effect` 输出和一个非法输出拒绝。
- Electron E2E：一次自然语言到时间轴标记的成功流程；一次非法结果不改变时间轴的流程。
- 手工 Mac 验证：选择已安装 CLI，输入一个受支持效果请求，确认反馈和时间轴标记。

本阶段达到以上三项验收即结束；不因“还可以更完善”继续扩展。
