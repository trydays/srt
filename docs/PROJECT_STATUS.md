## 已完成的能力（周期 1–4）

- 全片字幕：本地识别、全文编辑、保存草稿、应用、刷新恢复、重新生成及撤销。未应用草稿不进入成片。
- 区间调色：色温、亮度、饱和度、对比度；多个步骤按顺序叠加。
- 区间画面变换：水平/垂直翻转、0.25–4 倍中心等比例缩放，放大裁边、缩小补黑边。
- 静态图层：纯色矩形和纯文本可组合成卡片，按顺序遮挡；位置相对于视频内在画幅，支持指定出现区间，字幕在图层上方。
- 一次自然语言请求可包含多个步骤，整体提交并撤销最近一次请求；不合法的后续步骤不会留下半次编辑。刷新恢复，后续 AI 请求带上当前项目与已有操作，明确只输出本次新动作。
- 原有配色和总体布局保留。AI 能力目录仅公开已经接通执行、预览与导出的能力，不承诺任意算法或效果都已实现。

## 实际视频导出

- 右上角“导出视频”→ 另存为 → 实际 FFmpeg 成片，有进度与取消；保护源文件和已有目标，未应用字幕草稿会阻止导出。
- 固定 MP4 / H.264 / AAC / yuv420p，保留原画幅、时长和音轨。源画面调色/变换在下，文字/矩形按编辑顺序覆盖，字幕最后叠加。
- AI 只输出受校验的结构化数据；软件生成滤镜和固定文字文件，不执行模型提供的 Shell、路径或滤镜字符串。

- 内部完成度：共享关键帧、组合图层、严格参数校验、六个能力适配器、保存/撤销、预览、实际导出全部接通。默认 AI 目录已开放 `visual.group@1`，完整参数模式和已应用动画参数进入后续提示词；没有效果模板表或新的执行/存储系统。
- 透明度 0–1、组合缩放 0–2 倍，可给常量或 2–16 个关键帧；关键帧从组合起点计时，仅线性、缓出和固定轻微回弹。子元素先在视频内在画幅中合成，再整体变化；超出画幅被裁掉的文字不会因缩小重新出现。
- 范围仅新建组合的透明度、缩放及固定中心点；无位移/旋转关键帧、嵌套组合、引用旧图层改造、图片、个人技能库或新属性面板。源视频的已有缩放仍是静态区间操作。

- 仍只保留最近一次请求的撤销；不包含任意代码、新算法自动安装、通用 DAG、粒子/颗粒/暗角、个人技能积累复用。
