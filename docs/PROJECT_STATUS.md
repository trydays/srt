## 周期 1：最小统一执行主干

- 内部完成度：真实 Adapter 驱动的能力目录、单入口写入、版本检查、唯一字幕轨替换、一次撤销、最小线性 RenderGraph 与图驱动导出均已接入。
- 用户可见：字幕生成、全文编辑、保存草稿、应用、刷新恢复、再次生成并撤销、导出 MP4 可运行；颜色和布局不改。
- 旧字幕与旧撤销只读迁移，旧存储保留；草稿独立保存，未应用文字不进入预览或导出。
- AI 当前只公开实际接通的全片字幕能力。淡入、淡出、调色等未接通能力不再作为可执行能力承诺，也不产生假时间轴标记。

## 字幕视频导出：最低可用

- 用户可见：右上角“导出视频”→ 原生另存为 → 烧录字幕的 MP4；有真实进度与取消，字幕修改未应用会阻止导出，源与已有目标受保护。
- 内部：preload 四个窄方法 + 主进程单槽 `activeExport` + 页面级 `window.isExporting`；无通用锁、队列或任务中心。
- 渲染：固定 MP4 / H.264 / AAC / yuv420p，libass 白字 + 0.72 半透明黑底。
