# SRTP 当前项目状态

**状态日期：2026-09-07**

## 结论

字幕视频导出已达到“最低可用”：编辑器能把已应用字幕经系统原生另存为导出为烧录 MP4，冻结回归全绿。真实 GUI 手动整链（真实视频 → 本地 CLI → Whisper → 导出 → 外部播放器人工确认）仍未做，这不是发布或打包二进制声明。

## 字幕视频导出：最低可用

- 用户可见：右上角“导出视频”→ 原生另存为 → 烧录字幕的 MP4；有真实进度与取消，字幕修改未应用会阻止导出，源与已有目标受保护。
- 内部：preload 四个窄方法 + 主进程单槽 `activeExport` + 页面级 `window.isExporting`；无通用锁、队列或任务中心。
- 渲染：固定 MP4 / H.264 / AAC / yuv420p，libass 白字 + 0.72 半透明黑底。

## 验证

- 冻结回归：单元/集成 56 通过、0 失败、1 条件跳过；编辑器 E2E 9 通过、0 失败。
- 真实渲染（ffmpeg-full 9.0.1）：横屏 640×360 与竖屏 360×640 均烧录白字并保留音频；真实取消无伪产物、源未变。

## 限制

- 真实 GUI 手动整链（真实视频 → 本地 CLI → Whisper → 导出 → 外部播放器人工确认）待人工点验。
- 带显示矩阵旋转元数据的手机竖屏缺少忠实夹具，需真实手机片段复验。
