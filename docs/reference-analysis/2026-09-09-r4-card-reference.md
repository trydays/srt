## 与当前代码能力的对照

| 表达需求 | 当前状态 | 本轮判断 |
| --- | --- | --- |
| 底板与多段文字组成一张卡片 | 已支持 shape/text 组合；单组最多 16 层 | 复用现有组，不增加卡片模板注册系统 |
| 多张卡片错时出现、渐显、缩放 | 已支持组的时间区间、opacity/scale 关键帧及既有缓动 | 由 AI 组合多组与参数，无需新增通用动画引擎 |
| 圆角、细描边 | shape 目前只有位置、尺寸和纯色；Remotion 使用普通 SVG rect | 圆角是明确缺项；细描边需要通用样式表达，不写某个视频专属效果 |
| 同组中底板半透明、文字不变淡 | 当前透明度作用于整组，shape 本身无填充透明度 | 拆组能近似，但没有同组底板独立透明度；适合随底板样式补齐 |
| 图标、图片、圆角人像画中画 | 组合子层只有 shape/text，没有图片或第二视频子层 | 不把圆角矩形说成已支持圆角图片裁剪；另行讨论资源/视频层 |
| 粗体、微小标签、字距、自动排版 | 固定 Heiti SC、常规字重；可改字号/颜色并显式换行，无自动排版 | 可做简化文字层次，但不能完整还原参考字体外观；另列缺口 |
| 软阴影/外发光、背景模糊 | 当前卡片没有这些参数 | 阴影在第二组清晰可见；不能仅凭成片推定存在背景模糊。均不默认加入当前增量 |
| 独立平移动画、子层各自动画 | 当前组只有 opacity/scale；pivot 位移源于缩放，不是独立平移 | 如选择需精确位移的参考再补；不是本次观察必然要求的新平台 |

## 三种处理方式与建议

1. **不扩展能力，先做结构近似。** 使用现有矩形、文字、多组及关键帧，能表达信息卡和错时出现，但直角、文字风格及底板质感差异明显。
2. **建议：补一个“通用底板样式”增量。** 以 02:11–02:24 为参考，仅补圆角、描边、底板填充透明度；复用现有组、位置尺寸、时间区间及透明度/缩放动画。文字、卡片数、布局和颜色仍由 AI 根据需求组合，而非保存固定四卡脚本。参数名称、单位、范围和预算在目标获准后冻结。
3. **追求更完整的参考视觉。** 继续加入图标/图片、阴影、更多文字样式甚至画中画；这会扩展不止一个能力域，应拆成后续候选，不随本次分析自动开工。

建议选第 2 项。它能改善卡片底板的观感，但明确不包含参考图标、粗体/字距、阴影、画中画、自动布局/人物避让或动作逐帧复制；不要以“同类型卡片”暗示全部细节已经覆盖。用户若优先看重图标或动效而非底板，可调整所选增量后再冻结。
